# KDD 2027 Research Track Cycle 1 resubmit checklist

Status date: 2026-07-21 (Asia/Tokyo)

Official sources:

- CFP: https://kdd2027.kdd.org/research-track-call-for-papers/
- FAQ: https://kdd2027.kdd.org/frequently-asked-questions/
- OpenReview venue: https://openreview.net/group?id=KDD.org%2F2027%2FResearch_Track_Cycle_1
- Previous forum: https://openreview.net/forum?id=2b776YkXBX

## Submission form

- [ ] Select Research Track, Cycle 1.
- [ ] Set `Resubmission Flag` to `Yes`.
- [ ] Enter the previous OpenReview forum URL in the `Paper Link` field.
- [ ] Confirm the author list and order already frozen at the 2026-07-19 abstract deadline.
- [ ] Confirm every author profile contains five years of affiliations, homepage,
      DBLP when applicable, ORCID, advisors/relations, and recent publications.
- [ ] Nominate at least one qualified author-reviewer.
- [ ] Confirm conflicts and the maximum-seven-submissions rule.

## PDF package

- [x] One PDF, not a separate response-letter upload.
- [x] Page 1 is a one-page `Summary of Changes`.
- [x] The regular anonymous manuscript starts on page 2.
- [ ] Main paper is at most eight self-contained content pages after the summary.
- [ ] References follow the eight content pages.
- [ ] Optional appendix follows the references and uses the same format.
- [ ] ACM double-column review format:
      `\documentclass[sigconf,anonymous,review]{acmart}`.
- [ ] Remove all blue/red review markup from the final PDF after revision review.
- [ ] Do not append the old manuscript, reviews, or a separate rebuttal letter.
- [ ] Do not put an additional change list in the appendix.
- [ ] Verify anonymity, figures, hyperlinks, fonts, and visual rendering.

## Scientific readiness

- [x] Historical candidate code is isolated from the official TIFO path.
- [x] Main Ori--TIFO tables are generated from complete three-seed evidence.
- [x] TimeEmb and TFPS ETTm2/H96 results are verified.
- [ ] ETTh1/H96 TimeEmb and TFPS extension is complete and aggregated.
- [ ] Minimal reviewer-concern ablation and direct spectral evidence are complete.
- [ ] Every Summary of Changes statement points to a completed manuscript change.
- [ ] No placeholder table, figure, reference, or unsupported result remains.

## Deadlines

- Abstract deadline: 2026-07-19 AoE (passed).
- Full paper deadline: 2026-07-26 AoE.
- Author rebuttal period for the new review round: 2026-09-29 to 2026-10-13.
- Notification: 2026-11-14.

The September rebuttal is a later OpenReview response stage. It is distinct
from the one-page Summary of Changes required in the July resubmission PDF.
